# 🔍 江湖探案录

**武侠风格硬核推理解谜游戏** | 真探3 UI · 古风文案 · 移动端适配

---

## 🎮 游戏特色

- **真探3风格界面**：三栏布局 + 线索面板 + 任务解谜
- **古风武侠世界**：大梁国架空背景，陆小凤传奇风格
- **硬核推理玩法**：密室悬案、线索链分析、渐进式指认
- **移动端适配**：竖屏模式、触控友好
